# MaskShift Paper Build

From `experiments/MaskShift/paper`, run:

```bash
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
tectonic --print supplement.tex
tectonic --print submission_statements.tex
tectonic --print aaai27_readiness.tex
tectonic --print aaai27_preflight.tex
pdflatex -interaction=nonstopmode aaai27_official.tex
bibtex aaai27_official
pdflatex -interaction=nonstopmode aaai27_official.tex
pdflatex -interaction=nonstopmode aaai27_official.tex
pdflatex -interaction=nonstopmode aaai27_reproducibility_checklist.tex
```

`../PAPER.md` is the prose source of truth and `main.tex` is the synchronized
LaTeX submission draft. `supplement.tex`/`supplement.pdf` are generated by M17.
`submission_statements.tex`/`submission_statements.pdf` are generated by M18.
`aaai27_readiness.tex`/`aaai27_readiness.pdf` are generated by M19.
`aaai27_preflight.tex`/`aaai27_preflight.pdf` are generated by M20 as an
anonymous two-column US-letter page-pressure preflight.
`aaai27_official.tex`/`aaai27_official.pdf` are generated by M20 using the
official `aaai2027` kit. The official style requires pdfTeX, so use
`pdflatex`/`bibtex` for that file rather than Tectonic.
`aaai27_reproducibility_checklist.tex`/`aaai27_reproducibility_checklist.pdf`
are generated by M21 from the official checklist template and should be used as
the source for OpenReview checklist field entry.
